# Secure File Vault

A client-side zero-knowledge encrypted file vault with custom gradients and dark/light themes.

## Features
- Client-side AES-256-GCM encryption & PBKDF2 key derivation
- Dynamic Theme & Gradient Studio with dark/light mode toggle
- Optional Supabase integration for cloud storage & multi-device sync
- Ready for one-click hosting on Render (Static Site)
